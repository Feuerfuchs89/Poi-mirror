# Poi Mirror + Lernbaum

Clientseitige Poi-Übungs-App (GitHub Pages, ohne Build). Startseite ist der Lernbaum, jeder Skill öffnet den Kamera-Spiegel mit passendem Overlay und Quest-Zähler.

Alle Dateien liegen im Hauptverzeichnis (keine Unterordner):
index.html (Spiegel + Einbindung), tracker.js (Lichter-Tracking), tree.js (Lernbaum, Daten, Fortschritt), quest.js (Overlays, Zähler), tree.css, sw.js, manifest.webmanifest, Icons.

Fortschritt wird nur lokal im Browser (localStorage) gespeichert.
