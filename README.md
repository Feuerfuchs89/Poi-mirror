# Poi Mirror

Webcam-Spiegel für Flow Arts (Poi): LED-Tracking, Trails, Raster, Blumen-Muster, Metronom, Sektor-Sound, Delay-Replay und Aufnahme.

Die Kamera funktioniert nur über **HTTPS** – deshalb über GitHub Pages öffnen, nicht als lokale Datei.

## Veröffentlichen mit GitHub Pages

1. Neues Repository anlegen (z. B. `poi-mirror`).
2. Alle Dateien direkt in die Hauptebene hochladen (kein Unterordner): `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon-48.png`, `README.md`.
3. Repository → **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, Ordner `/ (root)` → **Save**.
4. Nach ca. einer Minute erreichbar unter `https://DEIN-NAME.github.io/poi-mirror/`.
5. Auf dem Handy öffnen, Kamera erlauben, im Browsermenü **Zur Startseite hinzufügen / App installieren**.
